# Academic CV

Edit `academic-cv.md` for content and `academic-cv.css` for typography,
spacing, colors, and page layout. Generate the linked, letter-size PDF with:

```sh
npm run build:cv
```

The command also writes `academic-cv.html` as a local rendering preview and
outputs the final PDF to `public/files/benjamin-steenhoek-cv-2026.pdf`.
